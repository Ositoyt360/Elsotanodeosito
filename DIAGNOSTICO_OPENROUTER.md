# Diagnóstico rápido

Esta versión activa OpenRouter en `server.js` y utiliza `openrouter/free`.

## Comprobar servidor

Con el servidor iniciado, abre:

`http://localhost:3000/api/ia/estado?probar=1`

Debe indicar que OpenRouter está configurado y mostrar el resultado de la prueba.

## Importante

Usa `http://localhost:3000` para probar esta copia. No uses una página antigua de GitHub Pages ni una instalación PWA anterior, porque esas pueden seguir mostrando JavaScript cacheado.
