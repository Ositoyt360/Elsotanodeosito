## 💻 API PÚBLICA EXPANDIDA

```javascript
// Expresiones
cambiarExpresion('thinking');           // Cambiar expresión
OsitoFace3D.agregarEmoji('x', '🎸', '🎶');  // Agregar custom

// Acceso a datos
OsitoFace3D.emojis.entrada              // Objeto con todos los emojis
OsitoFace3D.emojis.salida               // Objeto con salidas
OsitoFace3D.capas                       // Número de capas (7)
OsitoFace3D.rotacion                    // Grados de rotación (15)

// Control manual
OsitoFace3D.montar(element)             // Montar cara específica
OsitoFace3D.montarTodas()               // Montar todas las caras
```
