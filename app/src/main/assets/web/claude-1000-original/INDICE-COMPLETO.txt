   expresion.generarExpresion(p);
   sonidos.reproducirSonido(p.sonido);

🎭 ESTRUCTURA DE UNA PERSONALIDAD
────────────────────────────────────────────────────────────────────────────

Cada una de las 1000 personalidades incluye:

ID (3 dígitos)
   └─ Ejemplo: 001, 051, 305, 1000

Nombre
   └─ Ejemplo: "Triste", "Dramático", "Loco divertido"

Categoría (1 de 20)
   └─ Ejemplo: "Dramático", "Gracioso", "Especial"

Expresión Facial
   └─ Tipo de cara a mostrar: "sad", "funny", "mysterious"

Sonido Único
   └─ Sonido a reproducir: "suspiro", "risa", "bostezo"

Comportamientos (2-3)
   └─ Acciones físicas: "brazos abiertos", "mirada baja"

Reacciones (2-3)
   └─ Respuestas: "*suspira*", "*grita*"

Horarios (Opcional)
   └─ Para dormilonas: { inicio: 20, fin: 8 }
